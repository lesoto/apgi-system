🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GUI won't start:
    $ pip install matplotlib pyyaml numpy scipy

  Slow performance:
    - Reduce simulation speed slider
    - Close other applications
    - Check FPS counter in status bar

  Plots not updating:
    - Verify simulation is running (not paused)
    - Check FPS counter shows activity
    - Try Reset (F8)

  Memory issues:
    - Export data periodically
    - Reset simulation to clear buffers
    - Reduce buffer size in code if needed
